# Data card

Sixty original four-second synthetic episodes contain 21 normalized two-dimensional landmarks at 30 fixture frames per second. Forty development and 20 test episodes have different noise and occlusion levels. Gesture windows are generated ground truth. This project operates after landmark detection; it does not run a webcam, OpenCV, MediaPipe, biometric identification or a learned detector. Timings are fixture timestamps, not measured camera or system latency. Fixed thresholds are not validated for real users or safety-critical control.

All fixtures were generated specifically for this independent project. No upstream dataset, weights, media or result numbers were imported.
